# Content roadmap

The existing service and portfolio pages are the first priority. Publish new resources only when NEXT Studio can add first-hand examples and review every claim. The present Search Console connection returned no query or page rows, so this order is based on site relevance rather than invented search volume.

## Priority 1 — strengthen current pages

1. Review the five service pages with the owner for exact deliverables, revision policy, handoff format and realistic examples. The implementation now explains audience, process, exclusions, starting prices and two practical questions per service.
2. Review the five case studies against the original project files and live demos. CineVerse and FreelancerFlow remain personal projects; Pure Roots remains a concept. Add a screenshot only if it shows a real approved project state.
3. Keep the payment process, contact and pricing terms consistent. A quote and invoice follow a scoped conversation; this site does not run checkout.
4. After Search Console gains data, compare impressions and queries for `/services/*` and `/work/*`; revise descriptions and internal links where they do not match user intent.

## Priority 3 — verifiable authority

- Link from the owner's genuine developer/portfolio profiles to relevant NEXT Studio case studies where the owner wants that association public.
- Seek legitimate mentions through projects, collaborations and useful open-source work; do not purchase links or fabricate citations.
- Consider a Google Business Profile only if the business meets current eligibility rules and can present a truthful service area or in-person operation. The domain and WhatsApp country code do not establish a physical location.
